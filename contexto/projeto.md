## O que é este projeto
Landing Page promocional e informativa para Bom de Pesca (loja e 4º Torneio de Pesca em Itumbiara-GO).

## Stack e tecnologias
- Next.js 16.2.6 (App Router)
- React 19.2.4
- TailwindCSS v4
- TypeScript 5

## Estrutura de pastas relevantes
- `src/app/`: Páginas, layouts e estilos globais (`layout.tsx`, `page.tsx`, `globals.css`)
- `src/components/`: Componentes da interface (`Header`, `TorneioCards`, `ComunityCard`, `ContactCard`, `AnimateOnScroll`)
- `public/images/`: Imagens estáticas, brasão do 4º torneio, logo e mídias

## Decisões de arquitetura
- Next.js App Router para renderização
- Cards modulares para o 4º Torneio (Regulamento, Inscrição, Grupo de Avisos)
- Comunidade VIP e contato via WhatsApp integrados

## Estado atual
